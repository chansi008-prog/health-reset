# 건강 Reset 프로그램

그룹 건강관리 인증 PWA — 매일 것모닝·점심식사·것나잇·운동 체크 + 사진 1장.

- 화면: `index.html`, `style.css`, `app.js`
- 데이터: `store.js` (Firebase Realtime Database / 테스트 모드), `config.js`
- 보안 규칙: `database.rules.json` (Firebase 콘솔 → Realtime Database → 규칙에 붙여 넣기)
- 설정 방법: `Firebase_설정_가이드.md`

주소 뒤에 `?test=1`을 붙이면 서버 없이 이 기기 안에서만 동작하는 테스트 모드로 열린다.
